Notes

Leave a note

This project is being built by a few people at once. If you are one of them, every screen and every section has a way to say what you think. Notes go to a private inbox that only the team can read.

You need a GitHub account that has been invited to the inbox. Without an invitation, the note links show a "not found" page.

How it works

Three steps

  • Find the spot

    Every section on these pages has a "Leave a note on this" link. In the app, open Demo and tap "Leave a note on this screen".

  • Say it roughly

    A form opens on GitHub with the place already filled in. Pick the kind of note and write it however it comes.

  • Watch it land

    Notes are read before the next build session. When one has been dealt with, it is answered with what changed, then closed.
